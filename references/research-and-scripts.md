## Research and scripts

- Series premise: “I'm a Christian history nerd…” → one surprising, concrete historical detail → an attributable scholarly or primary-source explanation → how it illuminates Christian faith.
- Work within John's broadly Reformed Evangelical / The Gospel Coalition perspective. Keep the application focused on the episode's evidence.
- Historical claims need an actual quotation from a respected academic scholar or primary source. Prefer Christian scholars where suitable; appropriate historians such as Mary Beard remain suitable for Roman history. A pastor's popular article alone does not meet the scholarly-source requirement.
- Inspect the actual source text before quoting it. Check wording, context, page/section and attribution. Explicitly distinguish direct inspection, a quotation mediated through another author, inference, and an unresolved question. Never present remembered wording as a verified quotation.
- Research outlines should be Markdown with aggressive MLA-style citations and precise locators. Keep fuller qualifications there when the short script cannot carry them.
- Hooks should name 1–3 concrete historical anchors, use simple vocabulary and establish why the viewer should care. Surprising or extreme wording must remain supported by the evidence.
- **Scripts must contain 130–160 spoken words. 160 words is a hard maximum: never deliver a script or variant above it. Count all spoken dialogue, including the opening and quotations; exclude headings, citations and production directions. Count before handoff and trim any overrun. Keep the finished runtime under one minute and time the actual delivery.**
- In John's script pages, ordinary prose is drafted spoken text; bullet points are an outline unless otherwise indicated. Use the current designated written/blocking version, not an older variant.
- Scripture references in written materials must link directly to ESV.org, e.g. [John 13:14](https://www.esv.org/John+13+14).

### TikTok video description

When John asks for an episode's video description or its equivalent of “Sources for this short are:”, generate the concise source list below for direct copy/paste into TikTok.

1. Read the current episode's designated script/blocking script and source notes. Include the historical primary sources and scholarly works actually used in that video; do not carry over another episode's sources or list research leads and unused visual assets.
2. Check author, work title, and precise locators against the episode's verified source evidence. Use book/chapter/section numbers for ancient works; for modern books, include the publication year and relevant page(s). Preserve necessary attribution when a quotation is mediated through another author. Resolve conflicting or unverified locators before presenting them as confirmed; do not invent details.
3. Return only plain text: the exact opening “Sources for this short are:”, a blank line, then one source per line. No Markdown italics/bold, bullets, numbering, hyperlinks, code fences, preamble, or closing commentary. Use ordinary line breaks. Omit Bible passages and Bible editions from this description even when scripture is spoken in the video. Scripture links still apply in research/scripts where references are included.
4. Keep the description to this source list unless John asks for additional copy, hashtags, or other material. Fuller bibliographies and evidence qualifications stay in the research notes.

Format example (CHN12; use the current episode's own verified sources):

```text
Sources for this short are:

Pliny the Younger, Letters 10.96.3–4, 7–9
N. T. Wright, The New Testament and the People of God (1992), pp. 349, 360
```
